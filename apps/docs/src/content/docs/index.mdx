## The problem with form-heavy apps

Insurance portals, HR systems, government services, support desks — all share the same UX friction: the user has to navigate a menu of form types, pick the correct one, then fill 15–20 fields from scratch. Most users pick the wrong form. Most abandon halfway through.

The bottleneck is not the form itself. It's **model selection and data entry** — tasks that are trivially easy for an AI that has read the user's intent.

## Why not replace forms with chat?

Conversational AI interfaces are great for exploration. They are poor for structured workflows. A chat transcript cannot be directly validated, routed to a backend endpoint, or stored in a database without an additional (fragile) parsing step.

Forms map to backend contracts. A `POST /api/claims` endpoint expects `{ policyNumber, claimType, incidentDate, lossAmount }` — not a paragraph.

## The IntentForm approach

Define one `ModelDefinition` per backend entity. IntentForm's engine takes a single sentence of user intent, uses an AI provider to:

1. Pick the right model from your list.
2. Extract structured values that map to your schema.

The form pre-fills. The user reviews and submits. Your backend receives the same JSON it has always expected — no schema changes, no new storage format.

```
"I slipped on ice in the parking lot yesterday, twisted my ankle"
          │
          ▼ engine.parse(intent)
          │
          ▼ AI selects model + extracts values
{
  model: "accidentReport",
  values: {
    incidentDate: "2026-05-04",
    description: "Slipped on ice in parking lot, twisted ankle",
    injuryType: "minor"
  },
  confidence: 0.91
}
          │
          ▼ form pre-fills → user reviews → submit
```

## Install

```bash
pnpm add @intentform/core @intentform/react @intentform/provider-openai zod
```

```typescript
import { createIntentForm } from '@intentform/core'
import { IntentForm } from '@intentform/react'
import { openaiProvider } from '@intentform/provider-openai'
import { accidentReportModel } from './models/accident-report'

const engine = createIntentForm({
  provider: openaiProvider({ apiKey: process.env.OPENAI_API_KEY! }),
  models: [accidentReportModel],
})

export default function App() {
  return <IntentForm engine={engine} />
}
```
