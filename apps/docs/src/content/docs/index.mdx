## What it does

User types a sentence. IntentForm sends it to an AI provider, which returns structured JSON. The engine selects the best matching form model, pre-fills field values, and applies conditional logic — all before the user touches a single input.

**Core flow:**

```
intent (string) → AI provider → structured JSON → model selection
  → field pre-fill → rule evaluation → rendered form
```

## Minimal example

```typescript
import { createIntentForm } from '@intentform/core'
import { IntentForm } from '@intentform/react'
import { openaiProvider } from '@intentform/provider-openai'
import { z } from 'zod'

const contactModel = {
  id: 'contact',
  label: 'Contact Form',
  description: 'General contact or support request',
  useCases: ['contact', 'support', 'inquiry'],
  schema: z.object({
    name: z.string(),
    email: z.string().email(),
    message: z.string(),
  }),
  fields: [
    { id: 'name', type: 'text', label: 'Name', required: true },
    { id: 'email', type: 'text', label: 'Email', required: true },
    { id: 'message', type: 'textarea', label: 'Message' },
  ],
  rules: [],
}

const engine = createIntentForm({
  provider: openaiProvider({ apiKey: process.env.OPENAI_API_KEY }),
  models: [contactModel],
})

export default function App() {
  return <IntentForm engine={engine} />
}
```

| [Rules](./concepts/rules/) | Conditional logic: hide/show/require based on field values |
